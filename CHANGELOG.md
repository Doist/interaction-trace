# Changelog

## [0.1.0](https://github.com/Doist/interaction-trace/releases/tag/v0.1.0) (2025-02-05)

### Features

- Core interaction trace monitoring with `initInteractionTraceMonitor` and `signInteractionTrace`
- React integration via `useSignInteractionTrace` hook
- Support for pre-typed APIs via `signInteractionTrace.withTypes()`
- Device-aware sampling with CPU cores and memory bucketing
- LoAF (Long Animation Frame) attribution for performance insights
- Configurable trace reporting with custom reporters
